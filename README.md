# Secure CLI File Vault: Authenticated Encryption with AES-256-GCM & PBKDF2

## 1. Επισκόπηση Έργου 
Το παρόν project υλοποιεί ένα αυτόνομο εργαλείο γραμμής εντολών (CLI) σε Python για την ασφαλή κρυπτογράφηση και αποκρυπτογράφηση αρχείων οποιουδήποτε τύπου (`.txt`, `.pdf`, εικόνες, δυαδικά αρχεία). 

Σχεδιάστηκε εξασφαλίζοντας όχι μόνο το **απόρρητο (Confidentiality)** των δεδομένων, αλλά και την **ακεραιότητά τους (Integrity)** μέσω **Authenticated Encryption (AEAD)**.

---

## 2. Κρυπτογραφικός Σχεδιασμός & Αρχιτεκτονική

### Α. Παραγωγή Κλειδιού από Κωδικό (Key Derivation - PBKDF2)
Τα συνθηματικά χρηστών (passwords) έχουν χαμηλή εντροπία και δεν μπορούν να χρησιμοποιηθούν απευθείας ως κλειδιά AES. Για τη μετατροπή τους σε κρυπτογραφικό κλειδί 256 bits χρησιμοποιείται ο αλγόριθμος **PBKDF2-HMAC-SHA256**:
* **Cryptographic Salt (16 bytes):** Παράγεται μέσω κρυπτογραφικά ασφαλούς γεννήτριας ψευδοτυχαίων αριθμών (`os.urandom(16)`). Αποτρέπει επιθέσεις προϋπολογισμένων πινάκων (Rainbow Table attacks) και εξασφαλίζει ότι ίδιοι κωδικοί παράγουν διαφορετικά κλειδιά.
* **Work Factor (480.000 Iterations):** Αυξάνει σκόπιμα το υπολογιστικό κόστος, καθιστώντας πρακτικά αδύνατες τις επιθέσεις εξαντλητικής δοκιμής (Brute-force / Dictionary attacks) με χρήση hardware επιταχυντών (GPUs/ASICs).
* **Key Length:** 32 bytes (256 bits).

### Β. Αυθεντικοποιημένη Κρυπτογράφηση (AES-256-GCM)
Χρησιμοποιείται το **AES σε Galois/Counter Mode (GCM)**:
* **Nonce / Initialization Vector (12 bytes):** Παράγεται μοναδικό nonce (`os.urandom(12)`) για κάθε διαδικασία κρυπτογράφησης, αποκλείοντας επιθέσεις replay και διαρροές πληροφορίας λόγω επανάληψης keystream.
* **Authentication Tag (16 bytes):** Το AES-GCM παράγει ένα ενσωματωμένο tag πιστοποίησης. Αν κάποιος αλλοιώσει έστω και ένα bit του κρυπτογραφημένου αρχείου, η αποκρυπτογράφηση αποτυγχάνει αυτόματα με σφάλμα `InvalidTag`, προστατεύοντας από επιθέσεις παραποίησης (tampering/bit-flipping).

## 3. Δομή του Παραγόμενου Αρχείου (.enc Payload Layout)
Το παραγόμενο κρυπτογραφημένο αρχείο δεν περιέχει μυστικά δεδομένα στην επικεφαλίδα του, αλλά φέρει όλα τα απαραίτητα μεταδεδομένα για την αποκρυπτογράφηση:

```text
+-----------------------+----------------------+------------------------------------------+
|  PBKDF2 Salt (16 B)   |    Nonce (12 B)      |     Ciphertext + Auth Tag (Variable)     |
|      Offset: 0-15     |     Offset: 16-27    |               Offset: 28+                |
+-----------------------+----------------------+------------------------------------------+
